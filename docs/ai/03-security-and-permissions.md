# 03 — الأمان والصلاحيات

## القاعدة الأساسية

إظهار زر أو إخفاؤه في React ليس حماية. كل عملية حساسة يجب التحقق منها في backend أو Electron main قبل القراءة أو الكتابة.

## الهوية والجلسات

- استخرج actor/user من جلسة موثقة محفوظة/متحقق منها في الجانب الموثوق.
- لا تثق في actorId يرسله renderer.
- تحقق من أن الجلسة نشطة وأن المستخدم غير معطل وأن صلاحياته الحالية ما زالت صالحة.
- لا ترسل password أو password hash أو session token إلى الواجهة إلا الحد الأدنى الضروري، والأفضل إبقاء الأسرار في العملية الرئيسية.
- استخدم تحققًا آمنًا لكلمات المرور، ومقارنة مناسبة، وقفلًا/تقييدًا لمحاولات الدخول حسب تنفيذ المشروع المعتمد.
- لا تسجل كلمات المرور أو الرموز أو بيانات اعتماد خارجية في logs.

## نطاق البيانات

يجب اختبار وتطبيق العزل عند الحاجة حسب:
- المؤسسة / tenant.
- الفرع.
- النشاط التجاري.
- الدور.
- صلاحية العملية نفسها (قراءة، إنشاء، تعديل، اعتماد، إلغاء، تصدير، نسخ احتياطي).

يجب فرض النطاق في خدمات المجال والاستعلامات، وليس بالاعتماد على مرشحات العرض فقط.

## Electron وIPC

- contextIsolation=true وnodeIntegration=false وsandbox=true حسب الإعداد المعتمد.
- expose عمليات محددة في preload، لا واجهة عامة لتنفيذ أوامر أو SQL.
- تحقق من sender/frame/origin ومن شكل المدخلات لكل IPC حساس.
- لا تسمح بفتح روابط أو نوافذ خارجية بلا قائمة سماح وفحص.
- لا تكشف مسارات الملفات الحساسة أو مفاتيح التشفير للواجهة.
- لا تستخدم eval أو تنفيذًا ديناميكيًا غير موثوق.

## النسخ الاحتياطي والاستعادة

- النسخ والاستعادة عمليات إدارية حساسة وتتطلب مصادقة وصلاحية واضحة.
- افحص checksum وSQLite integrity/foreign keys إن كان ذلك مناسبًا.
- أنشئ backup قبل الاستعادة/الترقية، واستخدم ملفًا مؤقتًا ثم استبدالًا آمنًا.
- ارفض النسخة التالفة أو غير المتوافقة أو التي لا تطابق القيود.
- سجل العملية دون تضمين محتوى حساس.

## بيانات المؤسسة والخصوصية

- استخدم بيانات اصطناعية في الاختبارات، أو نسخًا منزوعـة الحساسية.
- لا تنقل أسماء أو هواتف أو عناوين أو أرقام حسابات أو فواتير حقيقية إلى تقارير أو prompts عامة.
- لا ترفع قاعدة بيانات إنتاج أو نسخة احتياطية إلى خدمة خارجية دون موافقة صريحة.
- أي اتصال أو مزامنة خارجية يجب أن يكون موثقًا ومحدودًا، ولا يضيف النظام اعتمادًا سحابيًا لمسار Windows المحلي دون قرار من المالك.

## مراجعة أمنية قبل الإصدار

راجع صلاحيات كل دور لكل عملية حساسة، عزل المؤسسة والفرع والنشاط، انتهاء الجلسة، تبديل المستخدم، قفل الدخول، IPC غير المصرح به، النسخ والاستعادة، وسجل التدقيق.
