# 00 — نظرة عامة على المشروع

## تعريف مختصر

هذا المستودع لنظام الإدارة التجارية والمحاسبية المتكامل، بواجهة عربية تدعم الأعمال التجارية والمخزون والمبيعات والمشتريات والمحاسبة والأطراف والصلاحيات. المستودع: sedeek7712/amro_TGAROH_GPT_22.

## التقنية الأساسية

- Frontend: React + TypeScript + Vite.
- Web storage: Dexie فوق IndexedDB.
- Windows desktop: Electron مع خدمات SQLite محلية عبر العملية الرئيسية وواجهة IPC.
- الاختبارات: TypeScript tests وNode tests وخطوات تحقق وبناء كما هي معرفة في package.json.

## افصل بين ما هو موجود وما هو مستهدف

وجود مساري Web وWindows في المستودع لا يعني أن كل الوظائف متطابقة أو أن كل مسار اجتاز قبولًا ميدانيًا. يجب على الوكيل فحص provider الذي يختاره dataService.ts والعمليات في الفرع الحالي، ثم توثيق أي اختلاف بين المسارين.

الاتجاه التشغيلي الذي اعتمده مالك المشروع لنسخة Windows هو تطبيق محلي مستقل أولًا، وقاعدة SQLite محلية، مع حفظ مستمر ونسخ احتياطي وتحديث لا يفقد البيانات. لا تضف اعتمادًا جديدًا على Supabase لهذا المسار المحلي. لا تحذف تكاملات المزامنة الموجودة في المشروع ما لم تكن المهمة المحددة تتطلب ذلك وموافقًا عليها.

## مبادئ تجربة الاستخدام

- نظام مؤسسي واضح، سهل لمستخدم غير تقني، مع كثافة معلومات بسيطة.
- واجهات عربية RTL متسقة، وتسلسل بصري مفهوم، ورسائل خطأ واضحة.
- لا تحسن الشكل عبر تغيير الحسابات أو نتائج المستندات.
- كل زر ظاهر يجب أن ينفذ الإجراء المعلن عنه، مع إظهار حالة نجاح/فشل حقيقية.
- حافظ على الوصول من الهاتف وWindows ما لم تكن المهمة مقيدة بمنصة واحدة.

## هوية المشروع والملكية

- لا تغيّر اسم المنتج أو هوية العميل أو العلامة التجارية دون توجيه.
- افصل هوية مالك/مطور النظام عن هوية المؤسسة والعميل النهائي.
- لا تضف بيانات تعريف شخصية أو أسرارًا إلى المستودع.
- يمكن توثيق دور مالك المشروع/المطور تحت TOOFAN SOFT فقط عندما يكون ذلك ضمن طلبه الصريح وسياق الملف.
