# نظام الإدارة التجارية والمحاسبية المتكامل

نظام عربي لإدارة الأنشطة التجارية والمحاسبة والمخزون والأمانات. الواجهة مبنية باستخدام React وTypeScript وVite، والتخزين التشغيلي المحلي باستخدام Dexie فوق IndexedDB.

## المتطلبات

- Windows 10 أو 11.
- Node.js 20 أو أحدث (يوصى بإصدار LTS).
- اتصال بالإنترنت عند تثبيت الاعتماديات لأول مرة فقط.

## التشغيل على جهاز Windows

1. نزّل المشروع كاملًا من المستودع وفك ضغطه.
2. ثبّت Node.js LTS 20 أو أحدث.
3. افتح مجلد المشروع وشغّل `run_windows.bat`.
4. في أول تشغيل، يثبت البرنامج الاعتماديات من ملف القفل ثم يبني نسخة الإنتاج.
5. يفتح النظام محليًا على `http://localhost:4173` ويعمل من نسخة الإنتاج.
6. اترك نافذة التشغيل مفتوحة، وأوقف النظام بالضغط على `Ctrl + C`.

للتشغيل اليدوي:

```powershell
npm ci
npm run preview -- --host 127.0.0.1 --port 4173
```

## بناء نسخة الويب الإنتاجية

```powershell
npm ci
npm run verify
npm run build
npm run preview -- --host 127.0.0.1 --port 4173
```

ملفات الإنتاج تخرج في مجلد `dist`. هذه الحزمة تطبيق ويب تقدمي (PWA)، ويمكن تثبيتها من المتصفح عندما تُقدَّم عبر عنوان HTTPS أو بيئة محلية مدعومة.

## حفظ البيانات والعمل دون إنترنت

- بيانات التشغيل تحفظ محليًا في IndexedDB داخل ملف تعريف المتصفح على الجهاز.
- لا تنتقل البيانات تلقائيًا إلى جهاز آخر، ولا يعني وجود المزامنة أن خادم المزامنة مهيأ أو متاح.
- فعّل النسخ الاحتياطي الدوري، واحفظ ملف النسخة خارج الجهاز.
- لا تمسح بيانات المتصفح أو تخزنه المؤقت قبل أخذ نسخة احتياطية والتحقق منها.
- عند تشغيل النظام على جهاز آخر، يلزم استيراد نسخة احتياطية أو إعداد خادم مركزي ومزامنة موثقة.

## حدود إصدار المستودع

هذا المستودع حاليًا تطبيق Vite/React PWA مع Dexie/IndexedDB. لا يتضمن في هذا الإصدار برنامج تثبيت Windows مستقلًا (EXE/MSI)، ولا تطبيق Electron/Tauri، ولا قاعدة SQLite، ولا خادم API مستقلًا. لذلك لا تعتبره بعدُ نظامًا مركزيًا متعدد الأجهزة أو بديلًا عن خادم إنتاج محمي.

قبل استخدامه في عمليات مالية حقيقية أو على عدة أجهزة، يجب اختبار النسخة على بيانات تجريبية، إعداد الخادم ومصادقة المستخدمين وسياسات قاعدة البيانات من جهة الخادم، والتحقق من النسخ الاحتياطي والاستعادة على جهاز منفصل.
