# Claude Code project entry point

Read [AGENTS.md](AGENTS.md) first. It is the canonical repository policy and must be followed.

Before acting, read the relevant documents in docs/ai/:
- 00-project-overview.md
- 01-architecture-and-data.md
- 02-accounting-and-inventory-safety.md
- 03-security-and-permissions.md
- 04-testing-and-release.md
- 05-decisions-and-open-gates.md

Start every task with a read-only inspection of the current branch and relevant code. Never edit main directly, never delete or mutate business data, and never change accounting behavior without explicit owner approval. Keep changes narrowly scoped and report actual tests and evidence. Do not claim a Windows release is production-ready based only on a successful build.
