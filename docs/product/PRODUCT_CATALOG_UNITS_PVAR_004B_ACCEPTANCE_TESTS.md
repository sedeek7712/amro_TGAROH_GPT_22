# PVAR-004B — مصفوفة اختبارات القبول الاصطناعية

- التاريخ: 2026-11-28
- الحالة: مواصفات اختبار فقط؛ لم تُنفذ بعد.
- المستودع: `sedeek7712/amro_TGAROH_GPT_22`
- النطاق: وحدات بديلة، التحويل الدقيق، الفواتير، خصومات المخزون، الدفعات، المرتجعات، التوافق والنسخ الاحتياطي.
- القاعدة: كل البيانات أدناه اصطناعية بالكامل. يمنع استخدام قاعدة المستخدم الحقيقية أو بيانات عملائه.

## 1. تجهيز بيانات الاختبار

أنشئ tenant وهميًا باسم `TENANT_TEST_UNITS` ونشاطًا وهميًا وصنفين. هذه البيانات تمثل fixtures مخططة للاختبارات الآلية لاحقًا، وليست قاعدة تم إنشاؤها أو اختبارًا تم تشغيله:

| الرمز | الصنف | وحدة المخزون الحالية | الرصيد الابتدائي |
|---|---|---|---:|
| SKU-A | قلم | حبة | 100.0000 |
| SKU-B | زيت | لتر | 20.0000 |

أنشئ دفعات اصطناعية لـ SKU-A: الدفعة `B-A1` بكمية 60 وتكلفة 2.00، والدفعة `B-A2` بكمية 40 وتكلفة 2.20. لا تنشئ بيانات فعلية أو حسابات إنتاجية.

الوحدات البديلة الاصطناعية:

| الصنف | الوحدة البديلة | المعامل إلى وحدة المخزون |
|---|---|---:|
| SKU-A | كرتون | 24 حبة |
| SKU-A | نصف حبة | 1/2 حبة |
| SKU-B | عبوة | 3/2 لتر |
| SKU-B | وحدة غير قابلة للتمثيل | 1/3 لتر |

## 10. اختبارات عدم التأثير

- أرصدة الحسابات المدينة والدائنة متوازنة قبل وبعد كل سيناريو.
- لا تغيير في الضرائب أو العملات أو طرق الدفع أو سياسة تكلفة البضاعة المباعة.
- لا تغيير في FIFO/FEFO أو المتوسط المرجح خارج إدخال كمية الأساس الصحيحة.
- لا تغيير في أرصدة الأصناف القديمة عند الترقية.
- فشل أي خطوة ذرية لا يترك سجلات جزئية.
- صلاحيات المستخدم وtenant/activity تمنع الوصول إلى وحدة SKU آخر.
- لا يمكن تعديل لقطة فاتورة مرحلة أو حذف وحدة مرتبطة بمستندات.

## 11. بوابة التنفيذ

هذه المصفوفة مواصفات وليست تقرير نتائج. عند الموافقة على تنفيذ منفصل:

1. تُحوّل الحالات إلى اختبارات آلية على fixtures اصطناعية فقط.
2. تُنفذ أولًا اختبارات التخزين والترقية والنسخ الاحتياطي دون تشغيل البيع والشراء.
3. لا تبدأ اختبارات البيع والشراء والمرتجعات قبل مراجعة عقودها والموافقة على نطاقها.
4. يُعرض تقرير لكل من SQLite وDexie مع حالات النجاح والفشل وأدلة CI.
5. لا تُستخدم قاعدة إنتاج أو بيانات المستخدم.

**لا تمنح هذه الوثيقة إذنًا بتعديل التطبيق أو إنشاء migrations أو الدمج.**
